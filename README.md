# 🎨 KEMON Sombreros y Accesorios

Bienvenidos al sitio web oficial de **KEMON Sombreros y Accesorios**, un espacio donde el arte, la cultura caribeña y la naturaleza se combinan en sombreros y accesorios pintados a mano sobre paja natural.

Este proyecto fue creado para mostrar las cinco líneas de productos elaboradas durante el 2025, junto a los servicios personalizados que ofrece Kelly Montes Buelvas, artista y fundadora de KEMON.

---

## 📌 Estructura del sitio

El sitio está organizado en las siguientes secciones:

- **Inicio:** Banner principal con imagen destacada.
- **Bienvenida:** Presentación de la artista y su inspiración.
- **Líneas de Productos:** Galería de imágenes con las cinco líneas:
  - Línea Carnavalera
  - Línea BIOdiversa
  - Línea Macondo
  - Línea Mí U
  - Línea Pickup
- **Servicios:** Descripción de servicios personalizados y talleres.
- **Contacto:** Formulario de contacto funcional (usando [FormSubmit](https://formsubmit.co)) y enlaces a redes sociales.
- **Pie de página:** Créditos de autor.
